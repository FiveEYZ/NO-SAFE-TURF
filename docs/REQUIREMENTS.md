## Current acceptance boundary

The project is a locally testable prototype. The most recent reported isolated MariaDB result is 15 passing cases, and the maintained Lua runner is Python-free. Neither result establishes FiveM Enhanced compatibility or deployment readiness. A production decision still requires an actual recipe install into a fresh test profile, Cfx startup, external MariaDB connectivity under the intended grants/TLS settings, two-client protocol, backup/restore rehearsal, and review of the generated package. Do not use real player data or a production database for these checks.
