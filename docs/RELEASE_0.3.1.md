# v0.3.1 — Enhanced fresh-install fixes

- Removed the recipe's Legacy `$minFxVersion: 12913` comparison, which rejects Enhanced build 177.
- The recipe downloads unchanged upstream oxmysql 2.14.3, then changes only its manifest server constraint from `/server:12913` to `/server:177`. This is a project compatibility adjustment, not an upstream release or proof of runtime compatibility. Node 22 remains selected. Use Enhanced artifacts; Legacy is not the target platform.
- Database URLs generated by txAdmin can contain raw slashes in passwords. The configuration reader now handles those delimiters before URL parsing. Regression coverage includes both encoded and raw credentials and the preloader conversion. Private JSON configuration remains available for credentials that cannot be represented unambiguously in a URL.
- OneSync is managed by recipe metadata and txAdmin, without a duplicate `set onesync` in the generated config.
- Includes a standalone English AMP conversion guide and optional Enhanced update scripts. User testing reached the Enhanced txAdmin setup page and updater download; a complete update/start cycle is not yet confirmed.

No database schema or gameplay changes. The recipe is for an empty installation database and rejects existing game tables. Do not reinstall over an existing deployment to upgrade it.

Validation: local JavaScript/Lua suites and recipe file replay are required before publication. Real Enhanced resource startup, oxmysql exports, client connection and multiplayer gameplay remain operator validation steps. This remains a prerelease.
